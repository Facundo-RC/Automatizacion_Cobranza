# Ecosistema de Automatización IA — Gestión de Cobranza

Proyecto final — Entrega de Automatización IA
Facundo Robaño Canti

Sistema que automatiza el triage de gestiones de cobranza: la IA (Claude) clasifica la prioridad de cada
deudor y redacta una propuesta de pago, un supervisor humano aprueba o rechaza por Slack, y solo tras la
aprobación se envía el email real al deudor.

**Tecnologías:** n8n · Notion · Claude (Anthropic) · Slack · Gmail

**Contenido del repositorio:**
- `Automatización_Cobranza.json` — lógica del flujo (n8n)
- `Diagrama_Arquitectura_Cobranza.pdf` — arquitectura y documentación técnica
- Capturas de evidencia del flujo en ejecución

**Base de datos en modo lectura:** [Gestiones de Cobranza — Notion](https://funny-impulse-30d.notion.site/Gestiones-De-Cobranza-3d36e348947c80188fb9dff237b73907)
